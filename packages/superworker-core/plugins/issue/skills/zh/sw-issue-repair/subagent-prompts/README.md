# subagent-prompts — 副本，正本在 `sw-conduct`

> 这个文件夹里是 `sw-conduct` 角色卡的**副本**：`fix.md`、`review.md` 与 `execute.md`，与
> `sw-conduct` 技能目录下 `subagent-prompts/` 里的同名文件一字不差。同级的 `../subagent-anti-patterns/`
> 也是这样来的：`sw-conduct` 同名目录里两张卡的副本。

为什么带副本：插件按文件夹各自装、各自卸。只装了 `issue` 时，`sw-conduct` 的目录可能根本不在本机，
而 `sw-issue-repair` 的每一批 Fix / Review 都要读这几份卡——指路指到空处，读的人只好自己编一份。

改哪一份：**改正本**（`sw-conduct` 的 `subagent-prompts/` 与 `subagent-anti-patterns/`），然后把同一份
拷到这里；只改这里等于让两条路说出两套规矩。
