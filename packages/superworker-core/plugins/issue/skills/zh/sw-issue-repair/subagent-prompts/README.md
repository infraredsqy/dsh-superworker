# subagent-prompts — 副本（正本位于 `sw-conduct`）

> 本目录存放 `sw-conduct` 角色卡的两份逐字节**副本**：`fix.md` 与 `review.md`，与 `sw-conduct/subagent-prompts/` 同名文件保持完全一致。

**保留副本的原因**：插件按目录独立安装与卸载。单独安装 `issue` 插件时，本机可能不存在 `sw-conduct` 目录，而 `sw-issue-repair` 每批 Fix / Review 都需要读取这两份角色卡。

**维护规则**：修改时**只改正本**（`sw-conduct/subagent-prompts/`），再将更新后的文件完整复制到本目录，避免两处出现分叉。
