# subagent-prompts — copies, the originals are `sw-conduct`'s

> What sits in this folder are **copies** of two `sw-conduct` role cards: `fix.md` and `review.md`,
> byte for byte the same files as the ones in the `sw-conduct` skill's own `subagent-prompts/`.

Why copies: a plugin is installed and removed by folder. With only `issue` installed, the `sw-conduct`
directory may not be on this machine at all, and every batch of Fix / Review in `sw-issue-repair`
reads these two cards — a pointer into nothing leaves the reader to invent one.

Which one to edit: **the original** (in `sw-conduct`'s `subagent-prompts/`), then copy it here. Editing
only this folder is how two roads come to state two different rules.
