# plugins/ — 仓库自带的三份插件：引擎不实现任何具体插件，插件也不进包出口

> 本文件是路牌，上限 15 行：一行一条——只说这一层有什么、什么时候看。

- `issue/` — 问题池：自带 `issue` 命令面与池子存储，收尾时认池子的加权读数，越过声明的线就往图里插一条维护节点，同一格度量只留一个活着的节点。加、改问题池行为时看
- `test-audit/` — 测试耗时度量：收尾时认交接单上报的实测秒数，越过声明的线就插一条维护待办，同一条线不重复。加、改这条度量时看它自己的路牌
- `pipeline/` — 管线自带的三份指令：conduct 带一个节点跑到收尾、route 改图、instruct 记一条约束；随发布件进技能目录，派发的第一行 `/pf-conduct` 靠它才有东西可读。改指令或加一份时看
