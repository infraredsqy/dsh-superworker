# src/ — Host half, model layer, and browser half: records read in, readings computed, panel drawn

> This file is a signpost, capped at 15 lines: one line per entry — only what this layer holds and when to read it.

- `host/` — Host half: the plugin entry, the service for those record and note endpoints, the native opener of a node's work session and the writer of its session note (`executor.ts`), the dispatch relay: the one path every dispatch walks — the panel's button or the relay itself — and the trigger that opens the next leg after a session closes, on a switch (`relay.ts`), the placement of the skills the shipped superworker plugins carry into the DSH skill root, and a session-side diagnostic read of them (`skills/`), the agent-facing `superworker` tool and the wake that arms it per agent — a `.superworker/` workspace at the step's start, or a pipeline skill load (`tool.ts`, armed by `wake.ts`), boundary shapes, data fetching and writing, the settings schema, and the one file every reach into the host context is read through (`seams.ts`). A refusal travels as a code (`failure.ts`), never as a sentence. Read when changing data fetching, the session opener, the dispatch relay, the tool's registration, or boundary shapes
- `model/` — Model layer: the four records and the session-note shape, plus one instant → the reading at that instant; pure functions, no data fetching, no DOM. Read when changing how readings are computed or the record shapes
- `client/` — Browser half: the main panel, the settings section, the two mount points in the dispatch-center panel, and the language layer (`words.ts` spells a fact, `locale.ts` attaches to DSH's own language service, `locales/` holds the lookup tables; a new language is a file beside `locales/zh.ts` with the same key set plus one line in `locales/index.ts`). Read when changing the UI or when adding a language
