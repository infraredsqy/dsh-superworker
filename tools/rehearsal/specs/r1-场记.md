# 排练场记：开场记录

> 模板注：判定块假定场地已 `git init`（`git status --porcelain` 才能字面执行）；落点一律写在场地（排练工作区根）内。
> 模板用法：立线后由指挥者把本模板抄进 `.superworker/nodes/<本节点>/spec.md`，`<本节点>` 以实战 uuid 替换。

## 目标

这条排练线的开场一格：证明一条线能从一个节点起步、走完一轮并留下记录，同时留下一份可读的开场场记。本轮不产出任何对外交付物。

## 落点

- 唯一落点：本节点自己的临时目录下的 `rehearsal-notes.md`
  （`.superworker/nodes/<本节点>/temp/`）。
- 只写这一份文件。项目根、其他节点的目录、图与线记录一概不碰。
- 临时目录不进版本库：这份场记属于过程记录，随 `temp/` 目录一起丢弃。

## 内容要求

1. 第一段：这一趟做了什么（一到两句，说清读到了哪些材料）。
2. 第二段：从读过的材料里摘一句原话，并注明出自哪份文件。
3. 全文非空行不超过 5 行。

## 完成判定

在项目根跑：

```pwsh
$p = ".superworker/nodes/<本节点>/temp/rehearsal-notes.md"
Test-Path $p                                          # 期望 True
(Get-Content $p | Where-Object { $_ -ne "" }).Count   # 期望 1..5
git status --porcelain                                # 期望无本节点 temp 之外的改动
```

通过判据：文件存在，非空行数落在 1 到 5 之间，除本节点的 `temp/` 外没有别的新增或改动。
