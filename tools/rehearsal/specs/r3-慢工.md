# 慢工：三段小传

> 模板注：判定块假定场地已 `git init`（`git status --porcelain` 才能字面执行）；落点一律写在场地（排练工作区根）内。
> 模板用法：立线后由指挥者把本模板抄进 `.superworker/nodes/<本节点>/spec.md`，`<本节点>` 以实战 uuid 替换。

## 目标

为三位虚构演员各写一段小传，作为这条线的第二份实物产出。这个节点刻意比「快工」慢：分三笔交付、逐个落盘，用来看清并行线里两条速度不同的分支各自怎么走。

## 落点

- 落点目录：项目根目录下的 `actors/`。
- 三份文件：`actors/alice.md`、`actors/bob.md`、`actors/carol.md`，各写一位。
- 三位人物的姓名与设定自拟，三份之间各自独立。

## 内容要求

1. 每份一份小传，正文三到四句，说清这位演员是谁、从哪儿来、眼下在忙什么。
2. 三份逐个落盘，写一份存一份。
3. 每份文件以这位演员的名字作标题行。

## 完成判定

在项目根跑：

```pwsh
$files = "actors/alice.md","actors/bob.md","actors/carol.md"
$files | ForEach-Object { "{0} {1}" -f $_, (Test-Path $_) }        # 期望三行都是 True
$files | ForEach-Object { "{0} {1}" -f $_, (Get-Content $_ | Where-Object { $_ -ne "" }).Count }   # 期望三行都不小于 3
(Get-ChildItem actors -File).Count                                 # 期望 3
```

通过判据：三份文件都在，每份非空行数不少于 3；`actors/` 下就是这三份文件。

本格与「快工」并行开工，`git status` 里会同时出现它的 `cheat-sheet.md`，那是另一格的产物，与本格判据无关。
