# 收尾：一张总单

> 模板注：判定块假定场地已 `git init`（`git status --porcelain` 才能字面执行）；落点一律写在场地（排练工作区根）内。
> 模板用法：立线后由指挥者把本模板抄进 `.superworker/nodes/<本节点>/spec.md`，`<本节点>` 以实战 uuid 替换。

## 目标

把整条排练线的产物收成一页总单，作为这条线走到终点的凭证：一眼看全这条线留下了什么。

## 落点

- 唯一落点：项目根目录下的 `finale.md`。
- 只写这一份文件。上游产物只读，不改。

## 输入

- 场记：开场那格留在它自己临时目录里的 `rehearsal-notes.md`。
- 「快工：一张小抄」的 `cheat-sheet.md`。
- 「慢工：三段小传」的 `actors/` 三份小传。
- 「闸口：等一声批准」的 `gate-summary.md`。

## 内容要求

1. 四行概括：场记、小抄、三段小传、闸口清单各占一行，每行说清这一格交付了什么、落在哪。
2. 一节收线结论，一句话：这条线走了哪几格、留下几份文件。
3. 全文不超过一页（非空行不超过 30 行）。

## 完成判定

在项目根跑：

```pwsh
$deliverables = "cheat-sheet.md","actors/alice.md","actors/bob.md","actors/carol.md","gate-summary.md"
$deliverables | ForEach-Object { "{0} exists={1}" -f $_, (Test-Path $_) }   # 期望五行都是 True
Get-ChildItem .superworker/nodes -Recurse -Filter rehearsal-notes.md | Select-Object -ExpandProperty FullName   # 期望一行
Test-Path finale.md                                                        # 期望 True
(Get-Content finale.md | Where-Object { $_ -ne "" }).Count                  # 期望 1..30
git status --porcelain                                                     # 期望只列出 finale.md
```

通过判据：五份上游交付全部在盘上，场记文件也在它自己的临时目录里；`finale.md` 存在且非空行数落在 1 到 30 之间；`finale.md` 里四格各出现至少一次；仓库里新增的只有 `finale.md`。
