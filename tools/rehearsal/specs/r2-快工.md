# 快工：一张小抄

> 模板注：判定块假定场地已 `git init`（`git status --porcelain` 才能字面执行）；落点一律写在场地（排练工作区根）内。
> 模板用法：立线后由指挥者把本模板抄进 `.superworker/nodes/<本节点>/spec.md`，`<本节点>` 以实战 uuid 替换。

## 目标

把这条排练线的要点压成一张随手可查的小抄，让没跟过这条线的人三十秒内看懂：这条线在排练什么、产物落在哪、闸口在哪一步。

## 落点

- 唯一落点：项目根目录下的 `cheat-sheet.md`。
- 只写这一份文件。图、线记录、其他节点的目录一概不碰。

## 内容要求

1. 开头一段：这条线要排练的动作，一句话。
2. 要点清单：三个到五个短条目，各写一件事（线名与并行度、产物落在哪、闸口停在哪个节点、收尾产出什么）。
3. 全文非空行不超过 10 行，条目各占一行。

## 完成判定

在项目根跑：

```pwsh
Test-Path cheat-sheet.md                                          # 期望 True
(Get-Content cheat-sheet.md | Where-Object { $_ -ne "" }).Count    # 期望 1..10
Get-Content cheat-sheet.md | Select-String "cheat-sheet|rehearsal" | Measure-Object | Select-Object -ExpandProperty Count   # 期望 >= 1
```

通过判据：文件存在，非空行数落在 1 到 10 之间，正文提到这条排练线。

本格与「慢工」并行开工，`git status` 里会同时出现它的 `actors/`，那是另一格的产物，与本格判据无关。
